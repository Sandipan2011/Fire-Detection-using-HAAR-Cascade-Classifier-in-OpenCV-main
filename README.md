# Fire-Detection-using-HAAR-Cascade-Classifier-in-OpenCV
cascade.xml is the classifier file that contains the parameters of classifier.      Arduino code should be uploaded separately

## Hardware Requirements

- **Webcam or Camera**: Required for video capture to detect fire in real-time.
- **Arduino Board** (e.g., Arduino Uno): Receives serial signals from the computer and controls response devices.
- **USB Cable**: Connects the computer to Arduino for serial communication.
- **LED**: Connected to Arduino pin 12 for visual fire alert.
- **Buzzer**: Connected to Arduino pin 11 for audible fire alert.
- **Water Pump or Solenoid Valve**: Connected to Arduino pin 13 for automatic fire suppression.
- **TV or Display Device** (optional): Connected to Arduino pin 10 for additional alert mechanism.
- **Wires and Breadboard**: For assembling and connecting the hardware components.
- **Power Supply**: USB power from computer or external battery for Arduino.

Note: The computer must have a USB port and a built-in or external camera.
